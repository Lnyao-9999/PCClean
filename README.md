# 全能磁盘清理专家（PCClean）

Windows 桌面端磁盘/系统清理软件，中文界面、面向新手。三大模块：**磁盘清理 / 软件卸载 / 内存优化**。
所有操作先扫描 → 分级 → 你确认后执行；支持**直接删除（真正释放空间）** 或 **移入隔离区（可回滚）** 两种方式。

---

## 一、启动方式

| 方式 | 说明 |
|---|---|
| **双击 `PCClean_Setup.exe`（安装包）** | 推荐用于**新电脑**。双击 → UAC → 自动装到 `C:\Program Files\PCClean`，创建桌面/开始菜单快捷方式，并在「设置 → 应用」中登记，可正常卸载。**安装包已内置运行环境，目标电脑无需安装 Python**。 |
| **双击 `PCClean.exe`** | 免安装直接运行。**自带便携 Python 运行时**；双击会自动弹一次 UAC 申请管理员权限，之后直接进入软件。 |
| **双击 `install.bat`** | 在当前电脑上安装到 `%LOCALAPPDATA%\Programs\PCClean` 并创建快捷方式。 |
| **`run-debug.bat`** | 排错用，带控制台窗口，能直接看到报错。 |

> 说明：软件目录下的 `python\` 是内置的便携 Python 运行时（约 46MB，含 tkinter），所以整个文件夹**拷到任何 Windows 10/11 电脑都能直接双击 `PCClean.exe` 使用**，不必安装 Python。
> 卸载请运行 `uninstall.bat`（只删程序，不删隔离区数据）。

## 二、① 磁盘清理（重点 C 盘）

### 使用流程
1. 点 **「开始扫描」** → 列表按体积从大到小显示可清理项。
2. 选择**清理方式**：
   - **直接删除（推荐）**：真正释放磁盘空间，删除后不可恢复。
   - **移入隔离区**：把文件挪到 C 盘内的隔离区，**不会释放空间**，但可回滚。
3. 单击行勾选/取消，或点 **「全选安全项(A)」**。
4. 点 **「开始清理」** → 完成后列表会**立即移除已清理项**，并弹出「C 盘实际释放了多少」。

### 能看到什么
- 顶部三个数字：**可清理总量 / 已选大小 / 隔离区占用**。
- 每项都带 **风险等级**：
  - **A·安全**：删了应用会自动重建，默认勾选。
  - **B·建议**：删了要重新下载或丢少量状态，默认不勾。
  - **C·需确认**：大件或会丢数据（如 Claude 本地虚拟机 8.6GB），弹窗确认。
- 覆盖：AI 客户端缓存（豆包/DeepSeek/ChatGPT/Claude 等）、系统缓存、浏览器缓存、开发缓存、各种更新器残留。

### 隔离区（重点说明）
- **位置**：`%LOCALAPPDATA%\PCClean\Quarantine`（即 `C:\Users\你的用户名\AppData\Local\PCClean\Quarantine`）。
- 在软件顶部点 **「隔离区管理」** 可以看到：位置（可一键打开文件夹）、条目列表、总大小。
- 在里面可以 **恢复所选 / 彻底删除所选 / 清空全部（释放空间）**。
- ⚠ 只要隔离区里还有文件，C 盘空间就没有真正释放——点「清空全部」才会释放。

### 专项功能
- **NVIDIA 旧驱动清理**：只删除「当前未使用」的旧驱动包，绝不动正在用的驱动；可先创建还原点。同时会把 `C:\NVIDIA` 等安装缓存列入扫描。
- **Claude 虚拟机删除询问**：扫描会列出 `Claude-3p\vm_bundles`（约 8.6GB，C 级），只有你确认不用 Cowork 时才删。
- **微信/QQ/剪映 迁移**：勾选数据 → 选目标盘 → 一键迁移（复制→改名备份→目录联接→验证，不删数据）。
- **改默认存储位置**：逐条教程，教你从根上防止 C 盘再被占满。

## 三、② 软件卸载
- **刷新列表**：枚举所有已装软件（64/32 位、每用户、UWP），自动过滤系统组件/补丁/运行库。
- **卸载**：调软件自带卸载程序并等待、验证是否真卸载。
- **卸载并清理残留**：卸载后扫描文件 + 注册表残留，弹清单让你勾选清理（文件进隔离区、注册表先备份 `.reg`）。
- **强制移除**：针对卸载程序损坏的情况，直接清理登记与残留。

## 四、③ 内存优化（诚实版）
- 实时显示内存总量/已用/可用/占用率；一键加速（刷新 DNS + 后台工作集让位）；开启游戏模式；高级清空备用内存。
- 不做「清注册表」「关虚拟内存」等有害操作。

---

## 五、安全设计
- **直接删除** 前有二次确认；**隔离区** 模式可 30 天内回滚。
- 硬保护名单：`System32 / WinSxS / Installer / Program Files / 用户文档/桌面/下载` 等绝不自动删。
- 不跟随 junction/符号链接；OneDrive 云端占位文件跳过；应用运行中不清理。
- 所有清理/卸载记录写入 `%LOCALAPPDATA%\PCClean\History`。

## 七、分发到新电脑 / 给其他用户

**方式一（推荐）：单文件安装包 `PCClean_Setup.exe`（约 19MB）**
1. 把这个 exe 拷到目标电脑（Windows 10/11，64 位）。
2. 双击 → UAC 选"是" → 自动安装到 `C:\Program Files\PCClean`。
3. 桌面/开始菜单出现「全能磁盘清理专家」快捷方式，双击即用（自动管理员）。
4. 卸载：`设置 → 应用 → 已安装的应用 → 全能磁盘清理专家 → 卸载`，或运行安装目录下的 `Uninstall_PCClean.exe`。

- 安装包内已**内置 Python 运行时**，目标电脑**不需要装 Python**。
- 安装包支持静默参数：`PCClean_Setup.exe /silent /target="D:\Apps\PCClean"`（noshortcut/noreg 可跳过快捷方式/注册）。

**方式二：绿色便携版**
- 整个 `PCClean` 文件夹拷过去，双击 `PCClean.exe` 即可，不写注册表、不装任何东西。

> 说明：本机 Python 是 3.15（较新），PyInstaller 等打包工具暂不支持该版本，因此采用「内置便携 Python 运行时 + 启动器 exe + 自解压安装包」的方案，效果等同于原生独立软件。
> 重新生成安装包：`powershell -ExecutionPolicy Bypass -File installer\build_setup.ps1`

## 八、常见问题

- **清理后 C 盘没变？** → 检查「清理方式」是否选了「移入隔离区」；隔离区模式只是把文件挪到 C 盘另一处，**不释放空间**。请选「直接删除」，或点「隔离区管理 → 清空全部」立即释放。
- **隔离区在哪？** → `%LOCALAPPDATA%\PCClean\Quarantine`，软件顶部「隔离区管理」可直接打开文件夹、恢复或彻底删除。
- **清理完列表还显示？** → 本版已修复：清理成功后立即从列表移除，并弹窗显示「C 盘实际释放」。若个别项清不掉，通常是程序占用或权限不足。
- **UWP/商店应用没列出来？** → 在极少数受限环境下 `Get-AppxPackage` 可能被拒；正常桌面双击运行即可正常枚举。
- **迁移后应用打不开？** → 目标盘必须是本机 NTFS 固定盘，应用要完全退出；迁移保留了 `*_backup`，可改回。
